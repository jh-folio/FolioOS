# Folio OS

**개인 투자자를 위한 로컬 우선 투자 리서치 워크스페이스**

[English README](README.md)

Folio OS 0.4.6은 내 PC에 저장한 시장 뉴스와 리서치 자료를 모아 일일 브리핑, 시장 맥락, 기업 분석, 근거 추적이 가능한 Deep Research로 정리해 주는 로컬 투자 리서치 도구입니다.

자료와 생성된 보고서는 기본적으로 내 컴퓨터에 저장됩니다. LLM/API 연동은 선택 사항이며, 사용자가 설정한 경우에만 사용됩니다.

---

## 0.4.6에서 할 수 있는 일

- Home 화면에서 Folio OS AI Agent와 대화하기
- Research Cockpit 대시보드에서 오늘 시장을 이끈 이야기, 최근 보고서에서 실제로 달라진 것, 종목·지수 차트, 시장 캘린더, Portfolio 연결 영향을 한 화면에서 점검하기 (Cockpit/Legacy 전환 버튼으로 기존 위젯 보드도 계속 쓸 수 있음)
- 그날 수집한 뉴스로 만든 이야기 비중 막대에서 각 이야기의 비중과 직전 거래일 대비 변화 확인하기 (비중 이동은 보도량 변화일 뿐 내용이 달라졌다는 뜻은 아닙니다)
- 변화 카드를 열어 무엇이 어떻게 달라졌는지 보기 — 새 정보·방향 전환·흐름 진전·보도량 이동 중 어디에 해당하는지, 짧은 이유, 그리고 직전과 현재를 나란히 비교
- 로컬 워치리스트에서 기업·섹터·테마를 추적하고 저지연 lead와 보고서 기반 Change Feed를 분리해 보기
- 이미 수집한 한국 RSS에서 빠르게 게시된 제목·링크만 모은 빠른 시장 신호 확인하기 (본문은 저장하지 않으며, 확인 전 정보는 보고서 근거나 중대한 변화 판정에 넣지 않음)
- 공개 RSS/뉴스 피드 수집 및 검색 (출처 필터에는 지금도 수집 중인 매체만 나오고, 기업 보도자료 와이어는 피드 화면에 보이지 않되 워치리스트·기업분석에서는 계속 쓰입니다)
- 미국/한국 시장 일일 브리핑 생성
- 중기 시장 상황을 요약한 Market Memory 확인
- 로컬 자료와 공식 데이터를 활용한 기업 분석 보고서 생성
- 투자 질문을 던지고 조사 계획을 확인·승인한 뒤, Smart Collection 조사 범위·사용 자료·내 생각이 구분된 보고서 받기
- 브리핑·기업분석·테마보고서·Market Memory 생성과 동시에 추가 Agent 호출 없이 규칙 기반 Change Intelligence 확인하기
- Portfolio 보유 종목을 관리하고(다른 곳에서 먼저 저장했으면 덮어쓰기 전에 알림), 증권사 화면 캡처를 crop·상단 가리기로 정리한 뒤 내 컴퓨터에 설치된 Tesseract로 보유 종목을 인식해 저장 전 직접 검토하기
- Watchlist/Portfolio 상담을 새로고침 뒤에도 이어가기. 상담 내용은 보고서 근거와 분리해 내 컴퓨터에만 보관하고, `노트로 정리`를 눌렀을 때만 투자 노트로 저장
- 보고서 옆에 내 생각을 적어 두고, AI 없이도 노트가 얼마나 오래됐는지·반대 근거·확인할 항목을 점검
- 관심 종목이 관련 리서치 화면에 조용히 연결되는 것 확인 (수량·가격·비중·노트 본문은 표시하지 않음)
- AI가 무슨 작업을 했는지 기록으로 확인하고, 보고서 수정 제안을 직접 승인하거나 거절하기
- 보고서 옆 Folio Note 작성
- 생성된 보고서를 Obsidian 또는 Notion으로 내보내기
- 전체 화면을 라이트·다크·시스템 테마로 전환하기
- LLM CLI/API, 모델 선택, RSS, 자동화, 화면, 내보내기 설정 관리

0.4.6 사용자 화면에 포함하지 않은 기능:

- 설치 프로그램/트레이 앱 수준의 마감 작업

저지연 뉴스는 검증된 근거가 아니라 초기 lead입니다. 이미 수집한 RSS 항목을 다시 읽어 표시할 뿐 추가 네트워크 호출·자격증명·별도 설정이 필요하지 않습니다. 페이지 스크래핑이나 유료 본문 우회를 하지 않습니다. 외부 Vision은 기본 비활성이고 crop 이미지마다 별도 동의가 필요합니다. 이미지 원본, raw OCR 텍스트, bounding box는 import 작업이 끝난 뒤 보관하지 않습니다.

## 설치와 실행

자세한 설치 및 실행 방법은 [installation.md](installation.md)를 참고하세요.

권장 경로는 두 가지입니다.

- **AI Agent에게 맡기기**: GitHub 링크를 Codex, Claude Code 같은 로컬 코딩 Agent에게 주고 설치와 실행을 요청합니다.
- **직접 설치하기**: Python 의존성을 설치하고, `.env.example`을 `.env`로 복사한 뒤 시작 스크립트를 실행합니다.

설치 후 Windows 빠른 실행:

```text
start-archive.cmd
```

설치 후 macOS / Linux 빠른 실행:

```bash
bash start.sh
```

실행 후 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8787
```

Folio OS를 사용하는 동안 서버 실행 프로세스는 닫지 마세요.

## 자료를 넣는 위치

사용자가 직접 제공하는 리서치 자료는 `research-inbox/` 아래에 넣습니다.

```text
research-inbox/
  articles/   # 저장한 기사, 웹페이지, 텍스트/마크다운/html 파일
  rss/        # RSS 수집 결과
  reports/    # 증권사 리포트, IR 자료, 리서치 PDF
  filings/    # SEC/DART 공시와 공식 문서
  links/      # URL 목록
```

Folio OS가 생성한 데이터는 `data/` 아래에 저장됩니다.

```text
data/
  briefings/
  company-analysis/
  topic-reports/
  investment-notes/
  caches and local databases
```

`data/`, `research-inbox/`, `config/`, `.env`는 로컬 설정과 생성물이 들어갈 수 있으므로 의도 없이 삭제하지 마세요.

## 주요 화면

### Home

Home은 AI Agent에게 투자 리서치를 요청하는 화면입니다. 입력창에 질문하거나 보고서 수정을 지시하고, 브리핑 생성·RSS 수집·기업 분석·딥 리서치는 빠른 실행 버튼으로 바로 시작할 수 있습니다.

아래쪽 Agent 작업 기록은 최근 상태만 한 줄로 보여주고, 펼치면 전체 기록을 확인할 수 있습니다. 작업 내용 원문이나 개인 자료는 표시하지 않습니다.

### Dashboard

화면 맨 위는 오늘의 이야기 비중입니다. 그날 수집한 뉴스가 어떤 이야기로 나뉘는지 막대 하나로 보여주고, 이야기마다 기사 수·비중·직전 거래일 대비 변화를 함께 적습니다. 비중이 움직였다는 건 보도량이 움직였다는 뜻이지 이야기의 내용이 달라졌다는 뜻이 아니며, 화면에도 그렇게 적혀 있습니다.

그 아래 `무엇이 달라졌나`에는 최근 보고서를 만들 때 확인된 변화가 쌓입니다. 카드마다 새 정보·방향 전환·흐름 진전·보도량 이동 중 무엇인지, 한 줄 이유, 그리고 펼치면 직전과 현재를 나란히 놓은 비교와 근거 기사가 있습니다. 해당 보고서를 열거나, 비교 기준이 된 보고서를 열거나, Agent에게 물어볼 수 있습니다.

나머지 영역은 종목·지수 차트, 시장 캘린더, 보유 종목 연결 영향입니다. Cockpit/Legacy 전환 버튼으로 기존 TradingView 위젯 보드를 계속 쓸 수 있고, 그 위젯은 출처 표기를 유지합니다.

### Watchlist

관심 기업·섹터·테마를 로컬 워치리스트에 저장하고 관련 뉴스 카드와 시장 반응을 확인합니다. 워치리스트 데이터는 로컬 워크스페이스에 남습니다.

### Briefing

일일 시장 브리핑을 생성하고 읽습니다. 브리핑은 뉴스/RSS 성격의 입력 자료와 가능한 경우 저장된 시장 스냅샷을 사용합니다. AI가 설정되어 있으면 더 풍부한 문장 생성에 활용하고, 사용할 수 없으면 규칙 기반 생성으로 대체됩니다.

### RSS Feed

공개 RSS/뉴스 항목을 수집, 필터링, 검색, 병합합니다. Folio OS는 유료 기사 접근을 우회하지 않습니다. 공개 RSS/링크 메타데이터와 사용자가 직접 저장한 자료만 사용합니다.

무료로 공개된 기사 본문은 로컬 보관용으로 함께 저장할 수 있습니다. Settings > 자동화 > RSS 수집의 `기사 전문 저장` 옵션(기본 켜짐)으로 켜고 끌 수 있으며, 저장된 본문은 브리핑과 검색 품질을 높이는 데 사용됩니다.

### Market Memory

중기 시장 상황을 하나의 현재 상태와 소수의 핵심 드라이버로 요약합니다. “지금 어떤 시장인지, 왜 그런지, 다음에 무엇을 봐야 하는지”를 빠르게 이해하는 데 초점을 둡니다.

### Company Analysis

공식 데이터와 로컬 리서치 자료를 활용해 기업 분석 보고서를 생성합니다. 미국 기업의 경우 SEC ticker/CIK 조회, companyfacts, 10-K/10-Q 성격의 근거 자료를 우선 사용합니다.

### Deep Research

투자 질문을 입력하면 조사 계획과 지금 쓸 수 있는 자료를 먼저 보여줍니다. 확인하고 승인해야 생성이 시작됩니다.

`분석 조건 추가`에서 내 생각이나 관심 종목을 덧붙일 수 있습니다. 이 내용은 **가설로만 전달되며 외부 근거로 쓰이지 않습니다**. 저장한 자료 모음(Smart Collection)을 골라 조사 범위를 좁힐 수도 있는데, 이 역시 검색 규칙일 뿐 근거 자체는 아닙니다. 규칙은 `data/smart-collections.json`에 저장되고, 상세 화면에서 현재 몇 건이 일치하는지와 지난번 대비 무엇이 바뀌었는지 볼 수 있습니다. 화면을 열거나 새로고쳐도 AI가 저절로 실행되지는 않습니다.

보고서는 `data/topic-reports/`에 저장되며, 본문과 함께 승인한 계획·사용한 자료 목록·부족한 자료·품질 평가·그때의 시장 상태를 남깁니다. 보고서 안에서 근거와 내 생각은 항상 구분해서 보여줍니다.

AI를 쓸 수 없으면 규칙 기반으로 보고서를 만들고 그 사실을 표시합니다. 쓸 수 있는 외부 자료가 하나도 없을 때는 사용자가 직접 확인한 경우에만 생성하며, 근거가 부족하다는 점을 보고서에 명시합니다. 이미 저장된 보고서 본문은 **수정 제안을 승인해야만** 바뀝니다.

### Agent Work Log

AI가 무슨 작업을 했고 어떻게 끝났는지를 한 줄씩 보여줍니다. 무슨 작업인지, 지금 상태가 어떤지, 무엇이 저장됐는지만 표시합니다.

**작업 내용 원문은 저장하지 않습니다.** 질문한 문장, 대화 전문, 보고서 본문, 수정 내역, 첨부 파일, 로컬 경로, API Key, AI 도구의 원본 출력은 기록에 남지 않습니다.

### 리서치 인텔리전스 경계

브리핑·기업 분석·딥 리서치는 AI 설정이 없어도 규칙만으로 판단할 수 있는 것들을 보여줍니다. 내가 적어 둔 노트가 얼마나 오래됐는지, 최근 자료와 어긋나는 지점이 있는지, 확인하기로 한 항목의 기한이 됐는지 같은 것들입니다.

관심 종목을 기록해 두면 관련된 리서치 화면에 조용히 연결됩니다. 이때 보유 수량·가격·비중과 노트 본문은 보여주지 않습니다.

**이 자동 표시는 읽기 전용이고 보고서 본문을 바꾸지 않습니다.** AI가 실제로 무언가를 해석하는 것은 `최신 근거로 검토`, `Agent에게 변화 묻기`, `Agent로 위험 설명`처럼 사용자가 직접 눌렀을 때뿐입니다.

이 화면들은 매수·매도를 권하지 않습니다.

### Settings

화면 테마와 움직임, AI Agent 모드, LLM CLI/API 설정, 저장된 모델 선택, RSS/자동화, Obsidian, Notion 설정을 관리합니다.

## 내보내기

### Obsidian

생성된 보고서를 로컬 Obsidian Vault로 내보낼 수 있습니다. Obsidian은 선택 사항이며, Folio OS를 사용하기 위해 필수는 아닙니다.

### Notion

설정에서 `NOTION_TOKEN`, `NOTION_DB_ID`를 구성하면 생성된 보고서를 Notion 데이터베이스로 내보낼 수 있습니다. 토큰은 운영체제 자격 증명 저장소에 보관됩니다.

## 프라이버시

Folio OS는 로컬 우선으로 동작합니다.

- 원천 자료는 `research-inbox/`에 저장됩니다.
- 생성된 보고서, 노트, 데이터베이스, 캐시는 `data/`에 저장됩니다.
- API Key와 토큰은 운영체제 자격 증명 저장소에 보관되며, `.env`에는 비밀이 아닌 설정만 남습니다.
- 클라우드 저장은 필수가 아닙니다.

AI/LLM 기능을 켜면 선택된 보고서 맥락이나 요약된 근거 자료가 설정한 Provider 또는 CLI 도구로 전송될 수 있습니다. 로컬 규칙 기반 동작만 원하면 AI 기능을 끄면 됩니다.

이전 `.env`의 비밀값은 자격 증명 저장소 이전이 성공한 뒤에만 제거됩니다. `.env`를 공유하거나 실제 API Key를 문서, 이슈, 채팅 로그에 붙여넣지 마세요.

## 문제 해결

브라우저가 자동으로 열리지 않으면 아래 주소로 직접 접속하세요.

```text
http://localhost:8787
```

의존성이 누락되었으면 아래 명령을 실행하세요.

```powershell
py -3 -m pip install -r requirements.txt
```

또는:

```bash
python3 -m pip install -r requirements.txt
```

AI 기능이 동작하지 않으면 다음을 확인하세요.
